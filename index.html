FROM IDEA TO GAME DAY

Your quick guide

1. Set the floor. Drag numbered players into position. Add players or defenders with the toolbar, then click the court. Select a player to change their number or give them the ball.

2. Draw the action. Choose Cut, Dribble, Pass or Screen. Drag from a player to the destination, or click the player and then the destination. Pass to a teammate to transfer possession. A screen line ends in a bar.

3. Build the sequence. Next step carries forward the end positions and ball possession. Actions in each step happen together. Use separate steps for actions that happen one after another.

4. Teach it. Add notes to each step. Play, pause, scrub, slow down or loop the animation. Select any step to edit it. Changes to an earlier step do not rewrite later steps.

5. Keep and share. Your playbook saves in this browser. Export a JSON backup to import on another device, a PNG of the current court, or print all steps to PDF. Share play creates a view-only snapshot link for your team. Players need no account. Links can be forwarded and cannot be individually revoked. Changes need a new link. Saved plays do not automatically sync between laptops.

Reading time: choose 3 or 4 minutes under Whole-play reading time. Time is shared across the steps: each moves for up to 3 seconds, then any remaining time holds the court and notes. With many steps, use longer durations or fewer steps to leave enough reading time. Change Step duration and Movement time to adjust individual steps. Playback speed changes the total viewing time; use 1× for the stated duration.

Publishing: the coach must link GitHub to publish or update the online app. Drawing, saving and exporting offline do not need GitHub. Players opening shared links do not need GitHub or a login.

Keyboard: V select · C cut · D dribble · P pass · S screen · T text · E erase · Space play/pause · Escape cancel · Delete selected object · ⌘/Ctrl Z undo. Focus a player and use arrow keys to move it; hold Shift for a larger move.

Starter plays are editable examples. Adjust them to your players and coaching system.
