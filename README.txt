COURTSIDE — USER GUIDE

MAC AND WINDOWS
Unzip the transfer file and open Courtside.html in a current Chrome, Edge,
Safari or Firefox browser. No installation is required. Drawing and saved
playbooks work offline. The app uses standard browser features on Mac and
Windows; it has been tested in the browser on Mac, not on a Windows device.

CREATE A PLAY
Choose New play and a formation. Drag numbered players with Select.
Choose Cut, Dribble, Pass or Screen, then drag from a player to a destination,
or click the player and then the destination. Pass onto a teammate.
Add defenders and court labels from the toolbar. Next step carries forward
end positions and ball possession. Add coaching notes to each step.
Actions within a step happen together. Use separate steps for successive
acts. Editing an earlier step does not rewrite later steps automatically.

THREE- TO FOUR-MINUTE ANIMATIONS WITH READING TIME
Under Whole-play reading time choose 3 minutes or 4 minutes. This distributes
the total time across your steps. Each step moves for up to 3 seconds, then
holds the final positions while the coaching notes remain on screen.
Duration is the total time for the step; Movement time controls how long
the players/ball move. The difference is reading time. You can change each
step independently, up to 300 seconds per step. Use 1x playback speed for
the stated total duration; 0.5x takes twice as long and 2x half as long.
Keep notes focused. On phones, Show full notes expands longer text.

SAVE AND MOVE BETWEEN LAPTOPS
Changes save in this browser when browser storage is available. They do not
automatically sync between laptops. To keep a file on your laptop or move
plays to another one, choose Export > Whole playbook, save the JSON file,
then choose Import playbook in Courtside on the other laptop. Import adds
copies and keeps existing plays. Browsers, local file paths and the online
app may have separate saved libraries. Use a permanent folder for the app.
Export backups regularly; private browsing or clearing browser data can
remove saved work. If saving is unavailable, the app shows a warning.

SHARE A LINK WITH YOUR TEAM
Click Share play, then Copy link. Paste it into WhatsApp, email or your
team chat. The link opens a view-only player with animation controls,
step selection, speed, looping and coaching notes. Players need internet
access to load the website. They do not need an account or GitHub.

Only the selected play is included. Each link contains a snapshot; changes
to your play require a new link. Links can be forwarded and cannot be
individually revoked. A very large play may exceed the messaging-link
limit; split it into shorter plays or use Download player file.

Download player file creates a self-contained animated HTML file, which
recipients can open in a desktop browser. It needs no connection after
download. Some email/mobile apps preview HTML as text; save it and open it
in a desktop browser. PNG export shares a static court image; JSON export
lets another coach import and edit a copy.

WHEN GITHUB NEEDS TO BE LINKED
The coach/administrator must link GitHub to publish or update the online
app using GitHub Pages. This is a publishing requirement, not a player
requirement. Players do not need GitHub or a login. Once the website is
published, creating ordinary play links does not need a GitHub login.
Offline drawing, saving, importing and exporting do not need GitHub.
The online viewer must remain published for team links to continue working.

KEYBOARD
V Select; C Cut; D Dribble; P Pass; S Screen; T Text; E Erase.
Space plays/pauses. Escape cancels. Delete removes the selected object.
Command/Ctrl Z undoes. Arrow keys move a focused player; Shift moves farther.

Starter plays are editable examples, not a reconstruction of a particular
team's playbook. Court proportions are illustrative. This app does not
include cloud sync, video export, practice scheduling or live substitutions.
